# Настройка обмена с 1С (CommerceML)

AtlasCMS поддерживает классический протокол обмена **CommerceML 2.09** — тот же,
который используют Битрикс, UMI и другие CMS. Он встроен в типовые конфигурации
1С: Управление торговлей, Розница, ERP, Комплексная автоматизация.

## 1. Подготовка сайта

1. Зайдите в админ-панель: `https://{домен}/admin`
2. Откройте **Настройки магазина** → **Обмен с 1С**
3. Задайте **логин** и **пароль обмена** (например, `1c` / сложный пароль)
4. Сохраните.

Адрес точки обмена: `https://{домен}/1c/exchange`

## 2. Настройка в 1С

В конфигурации (УТ 11 / Розница 2 / ERP) выполните:

1. **Администрирование → Обмены с веб-сайтами → Обмен с сайтом**
   (или «Публикация на веб-сервере» в старых версиях).
2. Создайте новый узел обмена, укажите:
   - **Адрес публикации сайта:** `https://{домен}/1c/exchange`
   - **Пользователь:** логин обмена из настроек магазина
   - **Пароль:** пароль обмена
3. В настройках обмена укажите:
   - выгружать **каталог товаров** (import.xml, offers.xml);
   - загружать **заказы** (документы заказа);
   - выгружать **статусы заказов**.

## 3. Как работает обмен

### Выгрузка товаров из 1С на сайт

1С инициирует сессию обмена по адресу `/1c/exchange`:

| Режим | Действие |
|---|---|
| `checkauth` | Проверка логина/пароля (Basic Auth), старт сессии |
| `init` | Сайт отвечает параметрами: `zip=no`, лимит файла |
| `file` | 1С передаёт файлы по частям (`import.xml`, `offers.xml`) |
| `import` | Сайт ставит файл в очередь и обрабатывает |

После обработки:
- **import.xml** — категории (дерево групп), товары, артикулы, штрихкоды,
  описания, характеристики, изображения, пометки удаления;
- **offers.xml** — типы цен, склады, цены и остатки.

### Загрузка заказов с сайта в 1С

| Режим | Действие |
|---|---|
| `query` | 1С запрашивает новые заказы, сайт отдаёт `orders.xml` |
| `success` | 1С подтвердила приём, заказы помечаются переданными |
| `import` (sale) | 1С возвращает заказы со статусами, сайт обновляет статусы |

## 4. Проверка

После первого обмена:

1. Откройте витрину — товары и цены должны появиться в каталоге.
2. Ошибки и статусы обмена видны в админке: **Платформа → Обмен с 1С**.

## Примечания

- Файлы хранятся в `storage/app/1c/{магазин}/` и обрабатываются потоково,
  поэтому обмен работает с очень большими каталогами.
- Товары, помеченные в 1С на удаление, автоматически деактивируются на витрине.
- Для работы очереди обработки нужен cron (см. `docs/SPACEWEB-DEPLOY.md`).
